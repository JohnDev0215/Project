1. วิธีการเก็บรวบรวมและใช้ข้อมูลส่วนบุคคลของคุณ

1.1 ฟังก์ชันพื้นฐาน ที่เราจัดเตรียมไว้ให้ขึ้นอยู่กับข้อมูลบางอย่างในการดำเนินการ หากคุณเลือกที่จะใช้ฟังก์ชันการนำทางพื้นฐานนี้ คุณจะต้องมอบหรืออนุญาตให้เราเก็บรวบรวมและใช้ข้อมูลที่จำเป็น ได้แก่:

1.1.1 เมื่อคุณเปิดใช้งาน Neusoft Navigation ครั้งแรก คุณสามารถใช้ฟังก์ชันการเปิดใช้งานได้ เราจะเก็บรวบรวมรหัส IVI เสมือนที่เข้ารหัส ข้อมูลตำแหน่งของคุณ เวลาเปิดใช้งาน สถานะการเปิดใช้งาน เวลาหมดอายุ รหัสประเทศ และเวอร์ชันข้อมูลแผนที่ เราจะใช้ข้อมูลตำแหน่งที่ตั้งของคุณเพื่อตัดสินว่าคุณอยู่ในเขตพื้นที่การให้บริการข้อมูลแผนที่ที่จัดเก็บเบื้องต้นหรือไม่ ดังนั้นโปรดเปิดใช้งาน Neusoft Navigation ครั้งแรกให้เสร็จสมบูรณ์ซึ่งจะอนุญาตให้คุณเข้าถึง Neusoft Navigation ได้ตามปกติ

1.1.2 เมื่อคุณใช้ฟังก์ชันการระบุตำแหน่ง เราจะรวบรวมข้อมูลตำแหน่งของคุณและข้อมูลความเร็วรถเพื่อแสดงตำแหน่งปัจจุบันของคุณ

1.1.3 เมื่อคุณใช้ฟังก์ชันการวางแผนเส้นทาง หรือฟังก์ชันการนำทาง เราจะเก็บรวบรวมข้อมูลเกี่ยวกับตำแหน่งและปลายทางของคุณ

1.1.3.1 เมื่อคุณใช้ฟังก์ชันตามที่ได้กล่าวมาแล้วข้างต้น คุณต้องมอบการอนุญาตของคุณเพื่อเปิดใช้การอนุญาตในการบอกตำแหน่ง การอนุญาตการเข้าถึงและการอนุญาตการอ่าน-เขียนดิสก์ คุณสามารถปิดการใช้งานการอนุญาตที่กล่าวมาแล้วข้างต้นผ่านทางการอนุญาตระบบเพื่อให้เราหยุดเก็บรวบรวมข้อมูลตามที่กล่าวมาแล้วข้างต้น แต่คุณจะไม่สามารถเข้าถึงบริการ หรือฟังก์ชันที่เกี่ยวข้องหรือรับผลลัพธ์ที่คาดหวังจากการบริการเหล่านี้

1.2 หากต้องการเปิดใช้งาน ฟังก์ชันเพิ่มเติม คุณสามารถเลือกให้เรา หรืออนุญาตให้เราเก็บรวมรวมข้อมูลต่อไปนี้

1.2.1 เมื่อคุณใช้ฟังก์ชันการจราจร เราจะรวบรวมข้อมูลตำแหน่งของคุณและข้อมูลการจราจรเพื่อแสดงสภาพการจราจรในบริเวณใกล้เคียง

1.2.2 เมื่อคุณใช้ฟังก์ชันการอัปเดตข้อมูลแผนที่ออนไลน์ เราจะรวบรวมรหัส IVI เสมือนที่เข้ารหัสและเวอร์ชันข้อมูลแผนที่เพื่ออัปเดตเวอร์ชันล่าสุดให้กับคุณ

1.2.3 เมื่อคุณใช้ฟังก์ชันการสืบค้น เราจะเก็บรวบรวมข้อมูลตำแหน่งที่ตั้งของคุณ และเนื้อหาที่คุณสืบค้น เพื่อมอบข้อมูลเกี่ยวกับตำแหน่งที่ตรงกับเนื้อหาที่คุณสืบค้นในบริเวณใกล้เคียงให้กับคุณ

1.2.4 เมื่อคุณใช้ฟังก์ชันการค้นหาของ Google เราจะรวบรวมผลการค้นหาของ Google ข้อมูลตำแหน่งของคุณ เนื้อหาที่คุณค้นหารหัส IVI เสมือนที่เข้ารหัส เวอร์ชันระบบปฏิบัติการ เวอร์ชันแพลตฟอร์ม เวอร์ชันแอป ประเภทยี่ห้อ ยี่ห้อ ID รุ่นรถ ID หน้าจอ IMEI ID ซัพพลายเออร์ ไทม์สแตมป์ เพื่อให้คุณได้รับข้อมูลเกี่ยวกับตำแหน่งใกล้เคียงที่ตรงกับเนื้อหาที่คุณค้นหา

1.2.5 เมื่อคุณใช้ฟังก์ชันรายการโปรด เราจะเก็บรวบรวมข้อมูลที่อยู่บ้าน ข้อมูลที่อยู่ที่ทำงาน และข้อมูลที่อยู่อื่นๆ ซึ่งคุณสามารถตั้งค่าได้อย่างอิสระ

1.2.6 เมื่อคุณใช้ฟังก์ชันพลังงานรูปแบบใหม่ เราจะเก็บรวบรวมข้อมูลรุ่นยานพาหนะของคุณ (ใช้พลังงานไฟฟ้าทั้งหมด ไฮบริด) ข้อมูลแบตเตอรี่ของยานพาหนะ (ปริมาณทั้งหมด ความจุและเปอร์เซ็นต์ของแบตเตอรี่ที่เหลือ ระยะทางที่สามารถเดินทางได้ของปริมาณแบตเตอรี่ที่เหลืออยู่ ข้อมูลแบตเตอรี่เหลือน้อย) และข้อมูลเชื้อเพลิงของยานพาหนะ (ข้อมูลเชื้อเพลิงเหลือน้อย) เพื่อแสดงสถานะปัจจุบันของยานพาหนะที่ใช้พลังงานรูปแบบใหม่ให้กับคุณ

1.3 เซิร์ฟเวอร์บริการหลังการขาย

ระหว่างที่คุณใช้งาน Neusoft Navigation เราจะบันทึกการทำงานของ Neusoft Navigation ภายใต้เส้นทาง IVI /sdcard/logs และ sdcard/navilog ของคุณในรูปแบบบันทึก

1.3.1 เมื่อมีปัญหาที่ต้องการให้เราช่วยวิเคราะห์และตรวจสอบ คุณสามารถติดต่อตัวแทนจำหน่ายในท้องถิ่นได้ หลังจากได้รับการอนุญาตจากคุณ ตัวแทนจำหน่ายจะดึงบันทึกของคุณส่งไปยังเซิร์ฟเวอร์บริการหลังการขายในประเทศเยอรมนี เราจะใช้บันทึกในเซิร์ฟเวอร์บริการหลังการขายเพื่อวิเคราะห์ปัญหา

ข้อมูลส่วนบุคคลที่อาจเกี่ยวข้องรวมถึง: รหัส IVI เสมือนที่เข้ารหัส เวลาเปิดใช้งาน สถานะการเปิดใช้งาน เวลาหมดอายุ รหัสประเทศ หมายเลขเวอร์ชันข้อมูลแผนที่ ข้อมูลตำแหน่งของคุณ ข้อมูลความเร็วรถ ข้อมูลการจราจร เนื้อหาที่คุณกำลังค้นหา ข้อมูลที่ปลายทาง ข้อมูลที่อยู่บ้านที่คุณตั้งค่า ข้อมูลที่อยู่ที่ทำงานที่คุณตั้งค่า และข้อมูลที่อยู่ที่คุณบันทึกไว้ ข้อมูลรุ่นรถของคุณ (ไฟฟ้าบริสุทธิ์ ไฮบริด) ข้อมูลเชื้อเพลิงของรถ (ข้อมูลสถานะระดับน้ำมันต่ำ) ความเร็วรถ ข้อมูลพลังงานของรถ การตั้งค่าระบบ (โหมดไฟ ภาษา เวลา ระบบเวลา สถานะหน้าจอ โหมดการขับขี่ หน่วย สิทธิ์) ผลการค้นหาของ Google เวอร์ชันระบบปฏิบัติการ เวอร์ชันแพลตฟอร์ม เวอร์ชันแอป ประเภทแบรนด์ แบรนด์ ID รุ่นรถ ID หน้าจอ IMEI ID ซัพพลายเออร์ และไทม์สแตมป์

1.4.2 เพื่อผลประโยชน์ที่ชอบด้วยกฎหมายของเราหรือบุคคลที่สาม

2.1 การประมวลผลที่ไว้วางใจได้

2.1.1 เพื่อที่จะมอบผลิตภัณฑ์และบริการที่สมบูรณ์แบบและมีคุณภาพสูงยิ่งขึ้นให้กับคุณ โมดูลหรือฟังก์ชันบางอย่างในฟังก์ชันพื้นฐานนี้ให้บริการโดยซัพพลายเออร์ที่เป็นบุคคลภายนอก ตัวอย่างเช่น เราอาจจ้างผู้ให้บริการเพื่อช่วยเราในการให้การสนับสนุนกับลูกค้า

2.1.2 สำหรับบริษัท องค์กรหรือบุคคลที่เราไว้วางใจในการประมวลผลข้อมูลส่วนบุคคล เราจะลงนามในสัญญาการเก็บรักษาความลับที่รัดกุมกับบุคคลเหล่านั้น และกำหนดให้พวกเขาประมวลผลข้อมูลส่วนบุคคลตามข้อกำหนด นโยบายความเป็นส่วนตัวนี้ และมาตรการเก็บรักษาความลับและความปลอดภัยที่เกี่ยวข้องของเรา

3. วิธีการปกป้องข้อมูลส่วนบุคคลของคุณ

3.1 เราได้ใช้มาตรการการป้องกันรักษาความปลอดภัยที่เป็นไปตามมาตรฐานอุตสาหกรรมในการคุ้มครองข้อมูลส่วนบุคคลที่คุณมอบให้จากการเข้าถึงโดยไม่ได้รับอนุญาต การเปิดเผยสู่สาธารณะ การใช้งาน การเปลี่ยนแปลงแก้ไข การทำลายหรือการสูญหาย

3.2 เราได้จัดตั้งระบบบริหารจัดการความปลอดภัยข้อมูลที่ทันสมัยกับข้อมูลตามแก่นสารและให้ความสนใจกับวงจรชีวิตของข้อมูลในอุตสาหกรรมนี้เพื่อปรับปรุงความปลอดภัยของข้อมูลส่วนบุคคลจากขอบเขตของการสร้างองค์กร การออกแบบระบบ การบริหารงานบุคคล และเทคโนโลยีผลิตภัณฑ์ เราได้เพิ่มความตระหนักของพนักงานเกี่ยวกับความสำคัญของการปกป้องข้อมูลส่วนบุคคลอย่างต่อเนื่องด้วยหลักสูตรการฝึกอบรมและการตรวจสอบ

3.3 สิ่งแวดล้อมทางอินเทอร์เน็ตไม่ได้มีความปลอดภัย 100% ดังนั้นเราจึงพยายามสุดความสามารถของเราในการรับรองหรือรับประกันความปลอดภัยของข้อมูลใดๆ ที่คุณมอบให้กับเรา หากสาธารณูปโภคการป้องกันทางกายภาพ ทางเทคนิคหรือทางบริการจัดการเกิดความเสียหาย โดยส่งผลให้เกิดความเสียหายต่อสิทธิและผลประโยชน์โดยชอบด้วยกฎหมายของคุณ เราจะเริ่มใช้แผนการฉุกเฉินอย่างทันท่วงที และใช้มาตรการที่เหมาะสมและจำเป็นเพื่อลดผลกระทบที่มีต่อคุณ

3.4 ในกรณีของสถานการณ์ความปลอดภัยใดๆ ที่ไม่คาดคิดที่เกิดขึ้น เราจะแจ้งให้คุณทราบอย่างทันท่วงทีเกี่ยวกับข้อมูลพื้นฐานและผลกระทบที่อาจเกิดขึ้นของสถานการณ์นั้นๆ มาตรการที่เรานำมาใช้หรือจะนำมาใช้ คำแนะนำเกี่ยวกับการป้องกันหรือการลดความเสี่ยง มาตรการการเยียวยาสำหรับคุณ ฯลฯ ตามกฎหมายและข้อกำหนด เราจะแจ้งข้อมูลที่เกี่ยวข้องให้คุณทราบทางจดหมาย การติดต่อทางโทรศัพท์ การแจ้งเตือนแบบพุช ฯลฯ หากมีความยากลำบากในการแจ้งเตือนเจ้าของข้อมูลส่วนบุคคลแบบตัวต่อตัว เราจะเผยแพร่การประกาศที่เกี่ยวข้องผ่านทางวิธีการที่เหมาะสมและมีประสิทธิภาพ ในขณะเดียวกัน เราจะรายงานการจัดการกับสถานการณ์ความปลอดภัยดังกล่าวตามข้อกำหนดของหน่วยงานการกำกับดูแล

3.5 ประกาศพิเศษ:

3.5.1 โปรดปกป้องข้อมูลส่วนบุคคลของคุณเมื่อคุณมอบตำแหน่งทางภูมิศาสตร์หรือสถานที่อยู่ของคุณผ่านซอฟต์แวร์ของบุคคลภายนอก

3.5.2 โปรดเข้าใจว่าการโจมตีที่เป็นอันตรายหรือไม่เป็นอันตรายต่างๆ อาจมีอยู่หรือเกิดขึ้น เนื่องจากการพัฒนาของเทคโนโลยีคอมพิวเตอร์และอินเทอร์เน็ตเป็นไปอย่างรวดเร็ว และข้อจำกัดของความเร็วในการซิงโครไนซ์ เราทำทุกอย่างที่เราทำได้ในการเพิ่มมาตรการความปลอดภัย แต่เป็นไปไม่ได้ที่จะรับประกันว่าข้อมูลมีความปลอดภัย 100% ทุกครั้ง

3.5.3 Neusoft Navigation ไม่สามารถควบคุมระบบและเครือข่ายการสื่อสาร หรืออุปกรณ์ฮาร์ดแวร์ที่คุณใช้งานกับผลิตภัณฑ์หรือบริการของเรา หรืออุปกรณ์ฮาร์ดแวร์ โปรดเข้าใจและปกป้องข้อมูลส่วนบุคคลของคุณ

3.5.4 หลังจากที่ข้อมูลส่วนบุคคลของคุณถูกทำให้ไม่สามารถระบุตัวตนได้แล้ว จึงจะเป็นข้อมูลที่สามารถนำมาใช้งานและส่งต่อๆ ไป Neusoft Navigation ไม่มีความจำเป็นที่จะแจ้งให้คุณทราบหรือรับความยินยอมของคุณสำหรับการจัดเก็บและการประมวลผลข้อมูลดังกล่าว

คุณยังมีสิทธิตามสถานการณ์ส่วนบุคคลใดๆ ในการคัดค้านการประมวลผลข้อมูลส่วนบุคคลของคุณเพื่อวัตถุประสงค์ในการทำวิจัยทางวิทยาศาสตร์หรือทางประวัติศาสตร์ หรือเพื่อวัตถุประสงค์ทางสถิติ เว้นแต่การประมวลผลดังกล่าวนั้นจำเป็นต่อการทำภารกิจเพื่อประโยชน์ของสาธารณะ

ข้อมูลส่วนบุคคลพื้นฐานบางอย่างมีความจำเป็นต่อประสิทธิภาพการทำงานของแต่ละฟังก์ชันการนำทาง สำหรับการเก็บและใช้ข้อมูลส่วนบุคคลที่เก็บเพิ่มเติมนี้ คุณสามารถเสนอหรือเพิกถอนการอนุญาตของคุณได้ทุกเมื่อ

คุณสามารถดำเนินการได้ตามวิธีการดังต่อไปนี้:

เมื่อการเพิกถอนความยินยอมของคุณได้รับการอนุญาตแล้ว เราจะไม่ประมวลผลข้อมูลส่วนบุคคลที่เกี่ยวข้องอีกต่อไป อย่างไรก็ตาม การตัดสินใจในการเพิกถอนของคุณจะไม่มีผลกระทบต่อการประมวลผลข้อมูลส่วนบุคคลก่อนหน้านี้ตามการอนุญาตของคุณ

คุณสามารถยกเลิกบัญชีที่ลงทะเบียนแล้วก่อนหน้านี้ของคุณได้ทุกเมื่อ โดยคุณสามารถติดต่อเราผ่านทางรายละเอียดการติดต่อที่อยู่ในบทความนี้

หลังจากที่บัญชีถูกยกเลิกแล้ว เราจะหยุดให้ผลิตภัณฑ์และการบริการกับคุณ และเราจะลบข้อมูลส่วนบุคคลของคุณตามที่กำหนดไว้ เว้นแต่กฎหมายและข้อกำหนดได้ระบุไว้

4.7 ความสามารถในการเคลื่อนย้าย

คุณมีสิทธิที่จะรับสำเนาข้อมูลส่วนบุคคลของคุณ คุณสามารถติดต่อเราผ่านทางรายละเอียดการติดต่อดังนี้

ตราบเท่าที่จะข้อปฏิบัติทางเทคนิคที่จะทำได้ เช่น ส่วนติดต่อข้อมูลที่จับคู่นั้นตรงกัน เราสามารถถ่ายโอนสำเนาข้อมูลส่วนบุคคลของคุณไปยังบุคคลที่สามตามที่คุณต้องการได้โดยตรง

4.8 จำกัดการตัดสินใจของระบบข้อมูลโดยอัตโนมัติ

ในบางฟังก์ชันการนำทางนั้น การตัดสินใจอาจเกิดขึ้นตามกลไกการตัดสินใจอัตโนมัติที่ไม่ใช่แบบประดิษฐ์เท่านั้น รวมถึงระบบข้อมูลและอัลกอริทึม หากการตัดสินใจดังกล่าวมีผลกระทบอย่างมากต่อสิทธิและผลประโยชน์ที่ชอบด้วยกฎหมายของคุณ คุณมีสิทธิที่จะขอคำอธิบายจากเรา และเราจะให้การเยียวยาที่เหมาะสม

4.9 การตอบสนองต่อคำร้องของคุณตามที่ได้กล่าวมาแล้วข้างต้น

เพื่อเป็นการรับรองความปลอดภัย คุณอาจจะต้องส่งคำร้องที่เป็นลายลักษณ์อักษร หรือพิสูจน์อัตลักษณ์ของคุณในวิธีทางอื่น เราจำเป็นต้องพิสูจน์อัตลักษณ์ของคุณก่อนที่จะตอบสนองต่อคำร้องของคุณ

เราจะตอบกลับภายในขีดจำกัดเวลาที่กฎหมายกำหนดไว้

สำหรับคำร้องของคุณที่สมเหตุผล ตามหลักการแล้วเราจะไม่คิดค่าธรรมเนียมใดๆ กับคุณ แต่สำหรับคำร้องที่ส่งมาซ้ำๆ ซึ่งเกินกว่าข้อจำกัดที่สมเหตุผล เราจะเก็บค่าใช้จ่ายบางอย่างตามความเหมาะสม เราจะปฏิเสธคำร้องที่เกิดขึ้นซ้ำๆ โดยปราศจากเหตุผลที่สมควรสนับสนุน เรียกร้องให้มีมาตรการทางเทคนิคที่มากเกินไป (เช่น การเรียกร้องให้พัฒนาระบบใหม่หรือการเปลี่ยนแปลงรากฐานของการปฎิบัติงานมีอยู่) ก่อให้เกิดความเสี่ยงต่อสิทธิและผลประโยชน์ที่ชอบด้วยกฎหมายของผู้อื่น หรือเป็นไปไม่ได้ที่จะปฏิบัติอย่างมาก (เช่น เกี่ยวข้องกับข้อมูลที่จัดเก็บในเทปสำรอง)

5. วิธีการประมวลผลข้อมูลส่วนบุคคลของผู้เยาว์

ผลิตภัณฑ์ เว็บไซต์และบริการของเราส่วนมากเหมาะสำหรับผู้ใหญ่ ผู้เยาว์ไม่ควรสร้างบัญชีโดยใช้ข้อมูลส่วนบุคคลของพวกเขาเองโดยปราศจากความยินยอมจากพ่อแม่หรือผู้ปกครองของพวกเขา

สำหรับการเก็บข้อมูลส่วนบุคคลของผู้เยาว์ที่ได้รับความยินยอมจากผู้ปกครองนั้น เราจะใช้เฉพาะ หรือเปิดเผยข้อมูลนี้สู่สาธารณะหากกฎหมายอนุญาต ได้รับความยินยอมอย่างชัดแจ้งจากพ่อแม่หรือผู้ปกครอง หรือความจำเป็นในการปกป้องผู้เยาว์

แม้ว่ากฎหมายและประเภณีท้องถิ่นนิยามคำว่าผู้เยาว์ไว้แตกต่างกัน แต่เราถือว่าผู้ใดก็ตามที่มีอายุต่ำกว่า 16 ปีเป็นผู้เยาว์

ในกรณีที่เราพบว่าตัวเราเองมีข้อมูลส่วนบุคคลใดๆ ที่เก็บรวบรวมมาจากผู้เยาว์ที่ไม่ได้รับความยินยอมล่วงหน้าจากผู้ปกครองของพวกเขา เราจะหาวิธีที่จะนำข้อมูลเหล่านี้ออกไปโดยเร็ว

7. วิธีการอัปเดตนโยบายความเป็นส่วนตัวนี้

นโยบายความเป็นส่วนตัวของเราอาจมีการเปลี่ยนแปลง

ในที่นี้เราจะไม่ละเมิดสิทธิของคุณโดยปราศจากความยินยอมที่ชัดแจ้งของคุณ โดยเราจะประกาศการเปลี่ยนแปลงใดๆ ที่มีต่อนโยบายนี้บนหน้านี้

สำหรับการเปลี่ยนแปลงที่สำคัญ เรายังจะส่งการแจ้งเตือนที่สังเกตุเห็นได้ชัดมากขึ้น (สำหรับบางบริการ เราจะส่งการแจ้งเตือนทางอีเมล โดยระบุการเปลี่ยนแปลงที่จำเพาะเจาะจงต่อนโยบายความเป็นส่วนตัวนี้)

การเปลี่ยนแปลงที่สำคัญต่อนโยบายนี้รวมถึงแต่ไม่จำกัดเพียง:

1. การเปลี่ยนแปลงที่สำคัญในโหมดการให้บริการของเรา เช่น วัตถุประสงค์ของการประมวลผลข้อมูลส่วนบุคคล ประเภทของข้อมูลส่วนบุคคลที่นำไปประมวลผล และวิธีการใช้ข้อมูลส่วนบุคคล

2. การเปลี่ยนแปลงที่สำคัญในโครงสร้างความเป็นเจ้าของ และโครงสร้างองค์กรของเรา ฯลฯ เช่น การเปลี่ยนแปลงเจ้าของเนื่องมาจากการปรับเปลี่ยนทางธุรกิจ การล้มละลาย การควบรวมและการเข้าซื้อกิจการ

3. การเปลี่ยนแปลงวัตถุประสงค์หลักสำหรับข้อมูลส่วนบุคคลถูกแชร์ ถ่ายโอนหรือเปิดเผยสู่สาธารณะ

4. การเปลี่ยนแปลงที่สำคัญต่อสิทธิของคุณในการเข้าไปมีส่วนร่วมในการประมวลผลข้อมูลส่วนบุคคล รวมถึงโหมดการใช้สิทธินั้น

5. การเปลี่ยนแผนกที่รับผิดชอบต่อความปลอดภัยของข้อมูลส่วนบุคคล ข้อมูลการติดต่อและช่องทางการร้องเรียน และ

6. รายงานการประเมินผลกระทบเกี่ยวกับความปลอดภัยของข้อมูลส่วนบุคคลที่ระบุว่ามีความเสี่ยงสูง

เราจะตรวจสอบอัตลักษณ์ของคุณด้วย "ความมั่นใจระดับหนึ่ง" หรือ "ความมั่นใจเป็นอย่างมาก" ตามความละเอียดอ่อนของข้อมูลส่วนบุคคล และความเสี่ยงที่จะเป็นอันตรายต่อคุณจากการเปิดเผยที่ไม่ได้รับอนุญาต หรือการลบ (ตามที่เกี่ยวข้อง) ก่อนที่เราจะดำเนินการคำร้องของคุณ เราอาจขอให้คุณมอบข้อมูลส่วนบุคคลเพิ่มเติมเพื่อตรวจสอบอัตลักษณ์ของคุณ
