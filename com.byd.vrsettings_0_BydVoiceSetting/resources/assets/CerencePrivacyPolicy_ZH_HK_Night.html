賽輪思雲端服務隱私權聲明

本賽輪思雲端服務隱私權聲明描述了賽輪思通常如何透過賽輪思指定的第三方雲端服務提供者收集和處理最終使用者請求。使用和結果可能會根據客戶特定的配置而有所不同。


平台概覽

賽輪思雲端服務 (CCS) 平台是賽輪思的多租戶、基於雲端的語音辨識和資訊娛樂解決方案。CCS 平台從車輛主機或客戶網關接收最終用戶請求，在賽輪思運行環境中處理這些請求，並將回應直接返回到車輛主機或透過客戶網關傳回給最終用戶。


我們收集的資訊

賽輪思根據客戶的授權，收集和處理最終使用者的聯絡人清單、客戶分配的外部使用者 ID、語音請求和命令以及上傳的文字資料（「服務資料」）。賽輪思對客戶外部 ID 進行假名化，並使用產生的內部 ID，以便資料可以連結到單一用戶，但無需任何有關該用戶的直接識別資訊。賽輪思不會透過技術手段處理口頭請求和命令來產生可用於識別資料主體的聲紋。


我們為什麼處理服務數據

賽輪思出於以下目的處理服務資料：

  • 提供CCS。 服務資料主要用於提供服務，包括最終用戶透過 CCS、車輛主機和 API 啟用的第三方服務。這包括處理以回應最終用戶的請求、確保服務按預期工作以及檢測和避免中斷或其他問題。

  • 維護和改進 CCS。 我們處理服務資料以提高 CCS 以及我們在車輛主機中提供的未來嵌入式模型的效能和功能。

  • 協助客戶。 我們在需要時使用服務數據，根據客戶的要求提供技術支援和專業服務。

  • 遵守法律義務和計費。 我們處理服務資料是為了遵守法律義務或出於計費目的。

資料儲存

賽輪思在不同地區維護生產伺服器（「運行時環境」），以處理來自客戶車輛主機的請求。在每個區域，CCS運行環境都部署在公有雲環境中。此配置基於與原始客戶流量的接近程度，以最大限度地減少延遲並優化效能。運行時環境自本隱私權聲明發布之日起位於以下位置：

  • 北美洲
    • 位於維吉尼亞州的公有雲
    • 通常用於處理來自美國、加拿大、墨西哥、南美洲、中美洲、紐西蘭、澳洲和亞洲（不包括中國）的客戶流量
  • 歐洲
    • 位於荷蘭阿姆斯特丹的公有雲
    • 一般用於處理來自歐洲、俄羅斯、中東和非洲的客戶流量
  • 中國
    • 位於中國上海和張家口的公有雲
    • 一般用於處理來自中國地區的客戶流量
  • 日本
    • 位於日本埼玉的公有雲
    • 一般用於處理來自日本和亞洲（不包括中國）的某些客戶流量

注意：作為容量規劃和流程最佳化的一部分，賽輪思可能會新增或變更這些位置。賽輪思將通知客戶此類計劃變更。

賽輪思也維護一個研究環境，從 CCS 執行環境接收語音資料日誌，供賽輪思研究人員用於各種 CCS 改進。賽輪思目前在美國僅維護一個研究環境，稱為賽輪思研究網格 (CRG)。 CRG 中的數據是根據其運行時形式聚合和假名化的。

賽輪思還維護一個商業智慧平台，用於處理客戶報告和帳單驗證的使用統計資料。 該平台在美國維護，客戶和賽輪思內部人員只能使用匯總資料。

在歐洲經濟區之外傳輸服務資料時，我們遵守歐盟委員會批准的示範合約條款框架，以確保充分的保護。


雲端安全

賽輪思雲端服務使用強大的安全功能來保護資訊免於未經授權的存取、變更和外洩。具體來說：

  • 賽輪思執行時間環境透過基於 VPN 的連線和基於政策的存取控制得到全面保護，以確保只有授權個人才能存取該環境。

  • 賽輪思利用我們的雲端服務提供的底層專用網絡，使用 SDN 技術在資料中心之間進行傳輸。

  • 賽輪思執行時期環境在加密磁碟上儲存敏感數據，包括使用者設定檔和日誌管理系統。

  • 賽輪思定期檢視其資訊收集、儲存和處理實踐，包括實體安全措施，以防止未經授權的存取其係統。

我們如何共享數據

我們不會與賽輪思以外的公司、組織或個人分享服務數據，但以下情況除外：

  • 當我們根據客戶的要求分享有關公司最終用戶的資訊時。

  • 當我們獲得最終用戶的同意時。

  • 用於提供雲端服務所需的處理。 我們向我們的附屬公司和其他值得信賴的企業提供信息，以便他們根據我們的指示並遵守本隱私權聲明和其他適當的保密和安全措施來處理這些資訊。

  • 基於法律原因，如果我們真誠地相信存取、使用、保存或揭露資訊對於遵守適用的法律、法規、法律程序或可執行的政府要求是合理必要的。

資料的刪除和保留

  • 賽輪思在執行時期環境中維護語音資料日誌長達28天支援調試和故障排除活動。 28 天后，語音資料日誌將會被刪除。

  • 語言模型註冊資料通常以上傳的聯絡人姓名的形式由客戶應用程式提供，以提高我們的雲端 ASR 模型的準確性。 使用者不活動六個月後將被清除。

  • 來自美國商業智慧平台的使用指標會保留四到五個月，以提供使用統計數據和計費目的。 這些指標本質上是聚合的，不包含口頭請求或命令。 產生的匯總報告最多可保留 13 個月。

  • 服務資料以三年滾動方式保留在 CRG 中。這些資料使賽輪思能夠透過訓練和建立迭代 AI 對話模型以及對系統故障進行錯誤分析來改善服務。

隱私權

在適用的情況下，資料保護法可以為最終使用者提供某些權利，包括存取、更正、刪除、反對和匯出其資訊的權利。
賽輪思 是資料處理者，根據客戶的授權，根據資料控制者（賽輪思的客戶）的指示收集和處理最終使用者資料。最終使用者可能擁有與其個人資訊處理相關的權利，並應聯絡資料控制者以行使任何此類權利。
