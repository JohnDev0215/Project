ประกาศความเป็นส่วนตัวของบริการ Cerence Cloud

ประกาศความเป็นส่วนตัวของ Cerence Cloud Services นี้อธิบายถึงวิธีที่ Cerence รวบรวมและประมวลผลคำขอของผู้ใช้ปลายทางผ่านผู้ให้บริการคลาวด์บุคคลที่สามที่ Cerence กำหนด การใช้งานและผลลัพธ์อาจแตกต่างกันไปขึ้นอยู่กับการกำหนดค่าเฉพาะของลูกค้า


ภาพรวมแพลตฟอร์ม

แพลตฟอร์ม Cerence Cloud Services (CCS) เป็นโซลูชันการรู้จำคำพูดและความบันเทิงบนคลาวด์ที่มีผู้เช่าหลายรายของ Cerence แพลตฟอร์ม CCS รับคำขอของผู้ใช้ปลายทางจากยูนิตส่วนหัวของยานพาหนะหรือเกตเวย์ของลูกค้า ประมวลผลคำขอเหล่านั้นภายใน Cerence Runtime Environment และตอบกลับไปยังผู้ใช้ปลายทาง ไม่ว่าจะโดยตรงไปยังยูนิตส่วนหัวของยานพาหนะหรือผ่านเกตเวย์ลูกค้า


ข้อมูลที่เรารวบรวม

Cerence รวบรวมและประมวลผลรายชื่อผู้ติดต่อของผู้ใช้ปลายทาง ID ผู้ใช้ภายนอกที่ลูกค้ามอบหมาย คำขอและคำสั่งที่เป็นคำพูด และข้อมูลข้อความที่อัปโหลด (“ข้อมูลบริการ”) ตามการอนุญาตของลูกค้า Cerence ใช้นามแฝงว่า ID ภายนอกของลูกค้า และใช้ ID ภายในที่เป็นผลลัพธ์ เพื่อให้สามารถเชื่อมโยงข้อมูลกับผู้ใช้รายเดียว แต่ไม่มีข้อมูลที่ระบุโดยตรงเกี่ยวกับผู้ใช้นั้น Cerence จะไม่ประมวลผลคำขอและคำสั่งที่เป็นคำพูดด้วยวิธีการทางเทคนิคเพื่อสร้างพิมพ์เสียงซึ่งสามารถใช้เพื่อระบุเจ้าของข้อมูลได้


เหตุใดเราจึงประมวลผลข้อมูลบริการ

Cerence ประมวลผลข้อมูลบริการเพื่อวัตถุประสงค์ดังต่อไปนี้:

  • จัดให้มีซีซีเอส ข้อมูลบริการใช้เพื่อให้บริการเป็นหลัก รวมถึงบริการของบุคคลที่สามที่ผู้ใช้ปลายทางเปิดใช้งานผ่าน CCS, เครื่องเสียงรถยนต์ และ API ซึ่งรวมถึงการประมวลผลเพื่อให้การตอบสนองต่อคำขอของผู้ใช้ เพื่อให้แน่ใจว่าบริการทำงานตามที่ตั้งใจไว้ และเพื่อตรวจสอบและหลีกเลี่ยงการหยุดทำงานหรือปัญหาอื่น ๆ

  • รักษาและปรับปรุง CCS เราประมวลผลข้อมูลบริการเพื่อปรับปรุงประสิทธิภาพและฟังก์ชันการทำงานของ CCS และรุ่นฝังตัวในอนาคตที่เรามีให้ในเครื่องเสียงรถยนต์

  • ช่วยเหลือลูกค้า. เราใช้ข้อมูลบริการเมื่อจำเป็นเพื่อให้การสนับสนุนด้านเทคนิคและบริการระดับมืออาชีพตามคำขอของลูกค้า

  • ปฏิบัติตามภาระผูกพันทางกฎหมายและการเรียกเก็บเงิน เราประมวลผลข้อมูลบริการเพื่อให้สอดคล้องกับภาระผูกพันทางกฎหมายหรือเพื่อวัตถุประสงค์ในการเรียกเก็บเงิน

การจัดเก็บข้อมูล

Cerence ดูแลรักษาเซิร์ฟเวอร์ที่ใช้งานจริง (“สภาพแวดล้อมรันไทม์”) ในภูมิภาคต่างๆ เพื่อประมวลผลคำขอจากหัวหน้าหน่วยยานพาหนะของลูกค้า ในแต่ละภูมิภาค CCS Runtime Environment จะถูกปรับใช้ในสภาพแวดล้อมคลาวด์สาธารณะ การจัดเตรียมจะขึ้นอยู่กับความใกล้ชิดกับการรับส่งข้อมูลของลูกค้าเพื่อลดเวลาแฝงและเพิ่มประสิทธิภาพการทำงาน สภาพแวดล้อมรันไทม์ ณ วันที่ประกาศความเป็นส่วนตัวนี้ อยู่ในสถานที่ดังต่อไปนี้:

  • อเมริกาเหนือ
    • ระบบคลาวด์สาธารณะที่ตั้งอยู่ในเวอร์จิเนีย
    • จัดเตรียมไว้โดยทั่วไปเพื่อรองรับการรับส่งข้อมูลของลูกค้าจากสหรัฐอเมริกา แคนาดา เม็กซิโก อเมริกาใต้ อเมริกากลาง นิวซีแลนด์ ออสเตรเลีย และเอเชีย (ไม่รวมจีน)
  • ยุโรป
    • คลาวด์สาธารณะที่ตั้งอยู่ในกรุงอัมสเตอร์ดัม ประเทศเนเธอร์แลนด์
    • จัดเตรียมไว้โดยทั่วไปเพื่อรองรับการรับส่งข้อมูลของลูกค้าจากยุโรป รัสเซีย ตะวันออกกลาง และแอฟริกา
  • จีน
    • ฐานคลาวด์สาธารณะ din Zhangjiakou และเซี่ยงไฮ้ ประเทศจีน
    • โดยทั่วไปจัดเตรียมไว้เพื่อรองรับการรับส่งข้อมูลของลูกค้าจากภูมิภาคจีน
  • ญี่ปุ่น
    • คลาวด์สาธารณะที่ตั้งอยู่ในไซตามะ ประเทศญี่ปุ่น
    • โดยทั่วไปจัดเตรียมไว้เพื่อรองรับปริมาณการใช้งานของลูกค้าบางส่วนจากญี่ปุ่นและเอเชีย (ยกเว้นจีน)

บันทึก: Cerence อาจเพิ่มหรือเปลี่ยนแปลงสถานที่เหล่านี้โดยเป็นส่วนหนึ่งของการวางแผนกำลังการผลิตและการเพิ่มประสิทธิภาพกระบวนการ Cerence จะแจ้งให้ลูกค้าทราบถึงการเปลี่ยนแปลงตามแผนดังกล่าว

Cerence ยังรักษาสภาพแวดล้อมการวิจัยที่ได้รับบันทึกข้อมูลคำพูดจาก CCS Runtime Environments เพื่อให้นักวิจัย Cerence ใช้สำหรับการปรับปรุง CCS ต่างๆ ปัจจุบัน Cerence มีสภาพแวดล้อมการวิจัยเพียงแห่งเดียวในสหรัฐอเมริกาที่เรียกว่า Cerence Research Grid (CRG) ข้อมูลใน CRG ได้รับการรวบรวมและใช้นามแฝงจากแบบฟอร์มรันไทม์

Cerence ยังคงรักษาแพลตฟอร์ม Business Intelligence ซึ่งใช้เพื่อจัดการสถิติการใช้งานสำหรับทั้งการรายงานลูกค้าและการตรวจสอบการเรียกเก็บเงิน แพลตฟอร์มนี้ได้รับการดูแลในสหรัฐอเมริกา และมีเพียงข้อมูลรวมเท่านั้นที่พร้อมใช้งานสำหรับทั้งลูกค้าและบุคลากรภายในของ Cerence

เมื่อถ่ายโอนข้อมูลบริการนอกเขตเศรษฐกิจยุโรป เราปฏิบัติตามกรอบการทำงานข้อสัญญาต้นแบบที่ได้รับอนุมัติของคณะกรรมาธิการยุโรป เพื่อให้มั่นใจถึงการป้องกันที่เพียงพอ


ความปลอดภัยของคลาวด์

Cerence Cloud Services ใช้คุณสมบัติความปลอดภัยที่แข็งแกร่งเพื่อปกป้องข้อมูลจากการเข้าถึง การเปลี่ยนแปลง และการเปิดเผยโดยไม่ได้รับอนุญาต โดยเฉพาะ:

  • สภาพแวดล้อมรันไทม์ของ Cerence ได้รับการปกป้องอย่างสมบูรณ์ผ่านการเชื่อมต่อที่ใช้ VPN และการควบคุมการเข้าถึงตามนโยบาย เพื่อให้แน่ใจว่าเฉพาะบุคคลที่ได้รับอนุญาตเท่านั้นที่สามารถเข้าถึงสภาพแวดล้อมนี้ได้

  • Cerence ใช้เครือข่ายส่วนตัวพื้นฐานที่ให้บริการคลาวด์ของเราเพื่อการถ่ายโอนระหว่างศูนย์ข้อมูลโดยใช้เทคโนโลยี SDN

  • Cerence Runtime Environments จัดเก็บข้อมูลที่ละเอียดอ่อน รวมถึงโปรไฟล์ผู้ใช้และระบบการจัดการบันทึกบนดิสก์ที่เข้ารหัส

  • Cerence จะทบทวนหลักปฏิบัติในการรวบรวม การจัดเก็บ และการประมวลผลข้อมูล รวมถึงมาตรการรักษาความปลอดภัยทางกายภาพ เพื่อป้องกันการเข้าถึงระบบโดยไม่ได้รับอนุญาต

เราแบ่งปันข้อมูลอย่างไร

เราไม่แบ่งปันข้อมูลบริการกับบริษัท องค์กร หรือบุคคลภายนอก Cerence ยกเว้นในกรณีต่อไปนี้:

  • เมื่อเราแบ่งปันข้อมูลเกี่ยวกับผู้ใช้ปลายทางของบริษัทตามคำขอของลูกค้า

  • เมื่อเราได้รับความยินยอมจากผู้ใช้ปลายทาง

  • สำหรับการประมวลผลที่จำเป็นในการส่งมอบบริการคลาวด์ เราให้ข้อมูลแก่บริษัทในเครือของเราและธุรกิจที่เชื่อถือได้อื่นๆ เพื่อประมวลผลข้อมูลให้เรา ตามคำแนะนำของเราและสอดคล้องกับประกาศความเป็นส่วนตัวนี้ รวมถึงมาตรการรักษาความลับและความปลอดภัยที่เหมาะสมอื่นๆ

  • ด้วยเหตุผลทางกฎหมาย หากเราเชื่อโดยสุจริตว่าการเข้าถึง หรือใช้ การเก็บรักษา หรือการเปิดเผยข้อมูลมีความจำเป็นตามสมควรเพื่อให้เป็นไปตามกฎหมาย ข้อบังคับ กระบวนการทางกฎหมาย หรือการร้องขอจากภาครัฐที่บังคับใช้

การลบและการเก็บรักษาข้อมูล

  • Cerence จะเก็บรักษาบันทึกข้อมูลคำพูดภายใน Cerence Runtime Environment ไว้สูงสุด 28 วันเพื่อสนับสนุนกิจกรรมการแก้ไขข้อบกพร่องและการแก้ไขปัญหา หลังจากผ่านไป 28 วัน บันทึกเสียงพูดจะถูกลบ

  • ข้อมูลการลงทะเบียนโมเดลภาษา โดยทั่วไปจะอยู่ในรูปแบบของชื่อผู้ติดต่อที่อัปโหลด ได้รับการจัดเตรียมโดยแอปพลิเคชันของลูกค้า เพื่อปรับปรุงความแม่นยำของโมเดล ASR บนคลาวด์ของเรา จะถูกลบถาวรหลังจากไม่มีการใช้งานเป็นเวลาหกเดือน

  • ตัวชี้วัดการใช้งานจากแพลตฟอร์ม Business Intelligence ในสหรัฐอเมริกาจะถูกเก็บรักษาไว้สี่ถึงห้าเดือนเพื่อให้สถิติการใช้งานและเพื่อวัตถุประสงค์ในการเรียกเก็บเงิน ตัวชี้วัดเป็นแบบรวมและไม่มีคำขอหรือคำสั่งที่เป็นคำพูด รายงานรวมที่ได้จะถูกเก็บรักษาไว้สูงสุด 13 เดือน

  • ข้อมูลการบริการจะถูกเก็บไว้ใน CRG เป็นระยะเวลาสามปี ข้อมูลนี้ช่วยให้ Cerence ปรับปรุงบริการได้โดยการฝึกอบรมและสร้างโมเดลการสนทนาด้วย AI ซ้ำๆ และดำเนินการวิเคราะห์ข้อผิดพลาดเกี่ยวกับความล้มเหลวของระบบ

สิทธิความเป็นส่วนตัว

ในกรณีที่เกี่ยวข้อง กฎหมายคุ้มครองข้อมูลอาจให้สิทธิบางประการแก่ผู้ใช้ รวมถึงสิทธิ์ในการเข้าถึง แก้ไข ลบ คัดค้าน และส่งออกข้อมูลของพวกเขา
Cerence คือผู้ประมวลผลข้อมูลที่ได้รับอนุญาตจากลูกค้า โดยจะรวบรวมและประมวลผลข้อมูลผู้ใช้ปลายทางตามคำแนะนำจากผู้ควบคุมข้อมูลซึ่งเป็นลูกค้าของ Cerence ผู้ใช้ปลายทางอาจมีสิทธิ์ที่เกี่ยวข้องกับการประมวลผลข้อมูลส่วนบุคคลของตน และควรติดต่อผู้ควบคุมข้อมูลเพื่อใช้สิทธิ์ดังกล่าว
