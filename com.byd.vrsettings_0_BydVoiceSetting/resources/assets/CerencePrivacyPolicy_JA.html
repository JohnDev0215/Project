セレンスのクラウドサービス 個人情報保護方針

このセレンスのクラウドサービスプライバシー通知では、セレンスが指定するサードパーティのクラウドサービスプロバイダを通じて、セレンスが一般的にどのようにエンドユーザーのリクエストを収集し、処理するかについて説明します。使用方法および結果は、お客様固有の設定によって異なる場合があります。


プラットフォームの概要

Cerence Cloud Services（CCS）プラットフォームは、セレンスのマルチテナント型クラウドベースの音声認識およびインフォテインメント・ソリューションです。CCSプラットフォームは、車両ヘッドユニットまたはカスタマーゲートウェイからエンドユーザーからのリクエストを受信し、Cerence Runtime Environment内でそれらのリクエストを処理し、車両ヘッドユニットに直接、またはカスタマーゲートウェイを介してエンドユーザーにレスポンスを返します。


当社が収集する情報

セレンスは、お客様の承認に基づき、エンドユーザーの連絡先リスト、お客様が割り当てた外部ユーザーID、音声リクエストおよびコマンド、アップロードされたテキストデータ（以下、「サービスデータ」）を収集および処理します。セレンスはお客様の外部IDを仮名化し、その結果得られる内部IDを使用することで、データを単一のユーザーにリンクさせることができますが、そのユーザーに関する直接の特定情報は一切含まれません。セレンスは、 音声によるリクエストおよびコマンド を技術的手段によって処理し、データ対象者を特定するために使用される可能性のある声紋を生成することはありません。


サービスデータを処理する理由

セレンスは、以下の目的でサービスデータを処理します：

  • CCSを提供する。 サービス・データは、主にサービスを提供するために使用されます。これには、エンドユーザーがCCS、車両ヘッドユニット、およびAPIを介して有効にするサードパーティ・サービスも含まれます。これには、エンドユーザーの要求に対する応答を提供し、サービスが意図したとおりに動作していることを確認し、機能停止やその他の問題を検出して回避するための処理が含まれる。

  • CCSの維持および改善。 当社は、CCSおよび当社が車両のヘッドユニットに提供する将来の組み込みモデルの性能と機能を向上させるために、サービスデータを処理します。

  • お客様のサポート お客様のご要望に応じて技術サポートや専門的なサービスを提供するために必要な場合、サービスデータを使用します。

  • 法的義務の遵守および請求。 当社は、法的義務に従うため、または請求の目的でサービスデータを処理します。

データ保管

セレンスは、顧客の車両ヘッドユニットからのリクエストを処理するため、各地域にプロダクションサーバー（「ランタイム環境」）を維持している。各地域において、CCSランタイム環境はパブリッククラウド環境にデプロイされる。プロビジョニングは、遅延を最小化し、パフォーマンスを最適化するために、顧客トラフィックの発信地に近い場所に基づいて行われます。本プライバシー通知の日付現在、ランタイム環境は以下の場所にあります：

  • 北米
    • バージニア州を拠点とするパブリッククラウド
    • 一般的に、米国、カナダ、メキシコ、南米、中米、ニュージーランド、オーストラリア、アジア（中国を除く）からの顧客トラフィックを処理するためにプロビジョニングされる。
  • ヨーロッパ
    • オランダのアムステルダムを拠点とするパブリック・クラウド
    • 一般的に、ヨーロッパ、ロシア、中東、アフリカからの顧客トラフィックを処理するためにプロビジョニングされる。
  • 中国
    • 中国の張家口と上海を拠点とするパブリック・クラウド
    • 一般的に、中国地域からの顧客トラフィックを処理するためにプロビジョニングされる。
  • 日本
    • 埼玉に拠点を置くパブリッククラウド
    • 一般的に、日本およびアジア（中国を除く）からの特定の顧客トラフィックを処理するためにプロビジョニングされる。

注：セレンスは、キャパシティプランニングおよびプロセス最適化の一環として、これらのロケーションを追加または変更する場合があります。 このような変更が予定されている場合は、セレンスがお客様にお知らせします。

セレンスはまた、CCSランタイム環境から音声データログを受信する研究環境も維持し、セレンスの研究者がCCSのさまざまな改良に利用できるようにしている。セレンスは現在、セレンス・リサーチ・グリッド（CRG）と呼ばれる研究環境を米国内に1つだけ維持している。CRGのデータは集約され、 仮名化された ランタイムフォームから。

セレンスはまた、顧客報告および請求検証のための利用統計を扱うビジネス・インテリジェンス・プラットフォームも維持しています。 このプラットフォームは米国で管理されており、顧客とセレンスの社内担当者の両方が利用できるのは集計データのみです。

サービスデータを欧州経済地域外に移転する場合、当社は欧州委員会が承認したモデル契約条項の枠組みに準拠し、適切な保護を確保します。


クラウドセキュリティ

セレンスのクラウドサービスは、不正アクセス、改ざん、開示から情報を保護するため、強力なセキュリティ機能を使用しています。具体的には

  • セレンスのランタイム環境は、VPNベースの接続とポリシーベースのアクセス制御によって完全に保護されており、許可された個人のみがこの環境にアクセスできるようになっています。

  • セレンスは、SDN技術を使用してデータセンター間の転送を行うために、当社のクラウドサービスが提供する基礎となるプライベートネットワークを利用します。

  • セレンスのランタイム環境は、ユーザープロファイルやログ管理システムなどの機密データを暗号化されたディスクに保存します。

  • セレンスは、システムへの不正アクセスを防止するため、物理的なセキュリティ対策を含め、情報の収集、保管、処理の慣行を定期的に見直します。

データの共有方法

当社は、以下の場合を除き、サービスデータをセレンス社外の企業、組織または個人と共有することはありません：

  • お客様のご要望により、当社のエンドユーザーに関する情報を共有する場合。

  • エンドユーザーの同意がある場合。

  • クラウドサービスを提供するために必要な処理のため。当社は、当社の関連会社およびその他の信頼できる事業者に情報を提供し、当社の指示に基づいて、本プライバシー通知およびその他の適切な機密保持およびセキュリティ対策に従って、当社のために情報を処理させます。

  • 適用される法律、規制、法的手続き、または法的強制力のある政府の要請に従うために、情報へのアクセス、情報の使用、保存、または開示が合理的に必要であると当社が誠実に信じる場合。

データの削除と保持

  • Cerence は、Cerence Runtime Environment 内の音声データログを最大で次の期間維持します。デバッグおよびトラブルシューティング活動をサポートするため、28 日間。28日後、スピーチデータログは削除されます。

  • 言語モデル登録データは、通常、アップロードされた連絡先名の形式で、当社のクラウドASRモデルの精度を向上させるためにお客様のアプリケーションから提供されます。このデータは、ユーザーが6ヶ月間使用しないと消去されます。

  • 米国を拠点とするビジネス・インテリジェンス・プラットフォームからの利用指標は、利用統計を提供し、請求の目的で4～5ヶ月間維持されます。測定基準は性質上集計され、音声によるリクエストやコマンドは含まれません。 結果としての集計レポートは最大13ヶ月間維持されます。

  • サービスデータは、3年単位でCRGに保持される。このデータにより、セレンスはAI会話モデルの訓練と構築を繰り返し、システム障害のエラー分析を行うことで、サービスを改善することができる。

プライバシー権

適用される場合、データ保護法は、エンドユーザーに対し、情報へのアクセス、訂正、削除、異議申し立て、およびエクスポートの権利など、一定の権利を提供することがあります。
セレンスはデータ処理業者であり、顧客の承認に基づき、セレンスの顧客であるデータ管理者の指示に従ってエンドユーザーのデータを収集および処理します。エンドユーザーは、個人情報の処理に関連する権利を有する場合があり、そのような権利を行使する場合は、データ管理者に連絡する必要があります。
