1.服务内容

1.1 “数字钥匙”是腾势汽车为用户提供的一种可以将手机或穿戴设备注册为车钥匙并可以实现解、闭锁车辆或启动车辆功能，您可以使用支持NFC功能的手机或穿戴设备，通过腾势数字钥匙注册流程将设备注册为车钥匙。具体支持的钥匙形态及功能随腾势车型实际配置及手机或穿戴设备支持能力决定。

1.2 本应用为您提供数字钥匙管理服务（包括钥匙开通、钥匙移除等功能；具体功能如有变更，请您及时留意我们的官方通知）。

1.3 您可前往车机端“车辆设置”--“门窗和锁”进入数字钥匙主页面，点击“使用手册”

查看数字钥匙使用方法、支持的手机或穿戴设备的品牌及型号。
